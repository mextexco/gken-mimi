# G検定 耳学習(PWA)

G検定の耳学習シナリオ①〜⑦を聞いて、小テストと合格の見込みで仕上がりを確認するアプリです。

## 使い方(Android)
1. ChromeでこのサイトのURLを開く
2. メニューの「ホーム画面に追加」(または「アプリをインストール」)
3. 「聞く」画面で、シナリオごとに音声ファイルを一度だけ選ぶ(端末の中に保存されます)

## できること
- 再生: 速度変更、5秒戻し・送り、続きから再生、ロック画面からの操作、バックグラウンド再生
- パートの頭出し・くり返し、スリープタイマー、次のシナリオへの自動再生
- 聞いた範囲と回数の見える化(9割聞くと1回)
- 小テスト(68問)と間隔反復による復習、間違えた所の音声へジャンプ
- 試験日までのカウントダウンとペース判定、合格の見込み
- PC表示 / スマホ表示の切り替え、バックアップの書き出しと読み込み

## データについて
音声と学習記録は端末のブラウザの中だけに保存され、外部には送信されません。音声ファイルはこのリポジトリに含めていません。

## 合格の見込みの計算
分野ごとに、小テストの成績(新しい回答ほど重く、21日で半分)を事前分布つきで集計し、本番では8ポイント低く見積もったうえで、分野の重みで合算します。145問のばらつきと推定のぶれを足して、正答率が合格ラインの目安(70%、非公式)を超える確率を出しています。参考値です。
